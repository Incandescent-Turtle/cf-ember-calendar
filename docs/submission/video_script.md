|---|---|---|

## Recording checklist

- [ ] Deploy first and record from the live URL, not localhost.
- [ ] Warm the Chilecito area and the Rekindle files before recording (no spinners on camera). Browser zoom 110 %, bookmarks bar hidden, one theme throughout.
- [ ] 1080p screen capture. Burn in captions (many judges watch muted).
- [ ] Record the voice-over separately, then cut the screen capture to it. Final length 0:29 to be safe.
- [ ] Upload, then open the link in a private window to check that it plays.
